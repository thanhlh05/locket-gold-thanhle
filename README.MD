# Locket Gold Full By Thanh Lê (Final 3.0)

Mở khóa toàn bộ tính năng Locket Gold một cách ổn định và mạnh mẽ.

## Tính năng chính

- Mở khóa **Locket Gold** vĩnh viễn
- Video tối đa **60 giây**
- Caption dài + hàng trăm caption Việt hóa đẹp
- Unlimited Friends
- Tắt quảng cáo hoàn toàn
- Giữ Badge Gold ổn định (không mất khi refresh)
- Force US Region (ổn định feature theo vùng)
- Multi-domain RevenueCat (`api.revenuecat.com` + `api.rc-backup.com`)
- Diagnostic page kiểm tra nhanh
- Hỗ trợ DNS chống thu hồi (NextDNS)
